# FocusFlow

A simple, beautiful deep-work timer for focused sessions and breaks.

Minimal UI, ambient background, customizable durations, task tracking, and session progress — all in a clean, distraction-free interface.

## Features

- **Focus / Short Break / Long Break** modes
- Circular progress ring with smooth animations
- Click the timer to set a custom duration
- Task input (shows in the header while running)
- Session counter (4 focus sessions → long break)
- Soft audio cue + toast notification when a session ends
- Dark, calm aesthetic with subtle animated orbs

## Quick Start

Just open `index.html` in your browser. No build step, no dependencies.

```bash
# or serve locally
npx serve .
```
